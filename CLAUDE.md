# SnapPy — project instructions

## Commit and PR attribution

**Do not attribute Claude in this repository.** When creating commits or pull
requests here, do **not** add `Co-Authored-By: Claude …` trailers, `🤖 Generated
with …` lines, or any similar AI-attribution note to the message or description.
Write the message as the author's own.

This overrides any default or harness-provided attribution guidance.
